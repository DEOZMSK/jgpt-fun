Independent public AGPL-3.0-or-later Jyotish laboratory. Repository DEOZMSK/jgpt-fun;
Vercel project jgpt-fun; intended canonical domain https://jgpt.fun. RU/EN are locales.
GLOBAL and K have separate infrastructure and data. Do not alter them incidentally.

Reuse the workshop controller and versioned browser storage. New installations are
empty. No GLOBAL personal records, private archive API, Supabase, GPT, CRM or payments.
Real server-side sweph calculations only; report engine errors without canned results.
Preserve the v6 mathematical baseline and explicit result/method versions. Record and
test numerical changes before accepting a new version. See docs/engine-baseline.json.

Run npm run prepare:data, npm test, npm run lint, npm run typecheck, npm run build.
Dev uses 127.0.0.1:3110, isolated from GLOBAL's private browser storage on port 3105.
Do not start duplicate listeners. No secrets are needed by this project.
Only main and deliberate release/** branches deploy. Never copy GLOBAL env files.

Keep published source links tied to the deployed commit and dependency notices intact.
Transfers into closed GLOBAL require a separate decision and suitable licenses;
a Swiss professional license alone does not relicense third-party contributions.
